# GL Journal Import Troubleshooting

## Purpose
Use this SOP to diagnose Oracle EBS General Ledger Journal Import errors.

## Prerequisites
Confirm ledger, accounting period, and source name before rerunning Journal Import.

## Procedure
Review rows in GL_INTERFACE and inspect concurrent request output for ORA- or APP- errors.

## Validation
Confirm accepted journals exist in GL_JE_HEADERS and GL_JE_LINES.
